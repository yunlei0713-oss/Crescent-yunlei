# Quick start

1. [Install](/en/guide/install) MoXun and configure a model provider and model.
2. Describe the problem and check the target. Use a connection card to open iTerm when needed; chat does not require a terminal.
3. Observation defaults to off. Select a mode and accept native confirmation to share terminal evidence.
4. The Agent analyzes and suggests; review and execute commands yourself in iTerm.
5. Continue with authorized evidence or manually supplied redacted output, then optionally confirm an SOP/Skill draft.

Example:

```text
Production Pods keep restarting. Suggest checks and explain their risks. Without observation evidence, do not claim to have inspected the cluster.
```

The Agent cannot connect, type, press Enter or apply remote fixes for you. Local file changes require separate [human approval](/en/guide/command-review). See [manual iTerm and observation](/en/guide/terminal) for evidence limitations.
