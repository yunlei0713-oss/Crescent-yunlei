# 为什么需要墨巡

运维排障不只需要生成命令，还需要核对主机与目标、理解风险、保留可靠证据并沉淀经验。

墨巡把聊天、人工 iTerm 协作、可选授权观察、Skills 与知识库串联起来。用户始终掌握终端操作；Agent 根据授权且脱敏的证据给出分析和建议，不自动执行、重启或修改远程环境。本地文件修改需要独立人工审批。

观察默认关闭，开启需原生确认。未观察时会明确说明证据缺口，不把建议写成已执行结果。SOP/Skill 先生成草稿，你确认后再保存。

见 [安装](/guide/install)、[快速开始](/guide/quick-start) 和 [终端观察限制](/guide/terminal)。
