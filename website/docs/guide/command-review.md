# 建议风险与文件审批

此页面保留旧地址，但旧的“命令审核后由 Agent 执行”模式已经退出。**Agent 永久不能执行、输入或中断终端命令**；低风险、白名单、用户批准和观察授权都不能改变这一点。

终端建议是文字。你检查目标和影响后，在 iTerm 自己输入并执行。风险提示不证明任意程序安全；复杂或高风险建议复制前仍需人工核对。复制操作只写剪贴板，不写终端、不按回车。

## 本地文件变更

`request_file_change` 提交变更提议，不直接修改文件。审批展示完整 Diff，并支持逐文件决定。Main 原生确认后再次校验路径、内容摘要、所属运行和时效，只消费一次授权，并验证写后内容。拒绝或失效时文件字节不变。
