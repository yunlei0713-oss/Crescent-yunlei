# 快速开始

1. 按 [安装](/guide/install) 打开墨巡，配置模型供应商和模型。
2. 描述问题并核对目标。需要连接时，从连接卡片打开 iTerm；只聊天不必打开终端。
3. AI 观察默认“不参与”。需要读取输出时，选择观察模式并通过原生确认。
4. Agent 给出分析和建议；你核对后在 iTerm 自行执行。
5. 根据授权证据或手动提供的脱敏输出继续分析，必要时确认 SOP/Skill 草稿。

示例：

```text
production 的 Pod 一直重启。请先给检查建议，说明风险；没有观察证据时不要声称已经检查过。
```

Agent 不替你连接、输入、按回车或实施远程修复。本地文件修改走独立人工审批，详见 [建议风险与文件审批](/guide/command-review)。观察限制见 [人工 iTerm 与 Agent 观察](/guide/terminal)。
