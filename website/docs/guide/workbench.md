# 工作台

墨巡保留左侧导航、中间聊天和固定 Composer。会话详情默认折叠，低频管理入口按需打开；终端操作在外部 iTerm，不再有内嵌终端布局或左右换位设置。

连接卡片用于打开 iTerm 并连接已保存目标。独立外置终端入口用于新建本机共享 iTerm 或绑定已有 iTerm，不隐式连接集群。每次协作可选择 AI 观察模式，默认不参与。

## 工作风格

极速、简洁、协作、详解控制说明密度，不改变安全权限。显示思考过程可覆盖风格默认值。任何风格都不能启用 Agent 终端执行，也不能绕过文件审批。

应用使用现有墨巡浅/深水墨主题。日志位于 `~/.crescent/logs`，按天分割并保留 3 天；可在设置选择级别。分享诊断信息前仍须检查敏感内容。
