# 人工 iTerm 与 Agent 观察

墨巡采用聊天优先工作区，不再提供内嵌 xterm 主面板。**用户在外部 iTerm 操作本地或 SSH 终端，Agent 只分析并建议**，不能输入、执行、中断或替你按回车。

## 流程 {#flow}

连接卡片打开 iTerm 并连接目标。独立外置终端入口可新建本机共享 iTerm，或绑定已有 iTerm；它不会自动连接集群。绑定已有终端是只读接入，解绑不发送 exit/Ctrl+C、不关闭你的 shell。

## 可选观察

- **不参与**：默认 off，不读取终端屏幕。
- **从现在开始观察**：原生确认后接收后续可用证据，不回放授权前内容。
- **加入当前上下文并继续观察**：原生确认后读取有限可访问文本快照，再观察新增内容。

观察不等于输入许可。快照不保证全部滚屏、完整输出、命令边界或退出码。证据经脱敏，仅在内存有界、短时保留。暂停、撤销、换身份或会话后停止采样并清除证据；恢复需重新确认，不回放暂停内容。

未授权时 Agent 可以按问题与目标信息给第一条建议，但必须说明尚未观察结果。你执行后，可授权观察或手动提供脱敏输出，再继续分析。见 [SSH 连接](/guide/ssh) 和 [建议风险与审批](/guide/command-review)。
