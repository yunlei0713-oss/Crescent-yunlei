# 墨巡使用与数据说明

## 一次排查协作

1. 打开墨巡即进入纯 AI 对话，侧栏默认收窄，可展开查看最近会话、集群／连接、知识与资料和设置；状态会记住。
2. 需要终端时，从连接卡片在 iTerm 登录，或用顶部外置终端入口新建本地 Shell／接入已有窗口、Tab、分屏。每次独立选择 AI 权限，默认不参与。也可直接聊天，按需粘贴截图或拖入日志／配置。
3. 可以**先描述要排查的问题，不必先输入终端命令**。Agent 根据问题和当前会话给出第一条命令／诊断片段；没有观察输出时明确注明。启用观察后，人工执行产生新证据，会主动给出 3 个相关诊断方向；明确目标或追问后收敛为一条下一步建议。
4. 命令读取／分析不设白名单，复杂管道、脚本、SQL、自定义 CLI 和输出也可分析；只对敏感内容做限制。建议的静态只读检查只是风险标签，不是读取或展示门槛。未知安全性／高风险建议需先确认风险，再“仅复制”；由你检查并在终端执行。
5. 最新建议是主内容，与分析结果共用正常滚动区，不会遮挡下方内容。后续人工执行继续围绕已有目标建议；草稿和用户对话优先，可点击「暂停主动建议」单独暂停模型分析。普通聊天不显示协作面板。思考和 Token／上下文详情默认折叠。

Swift、Concise、Guided、Teach 只影响讲解长度。所有风格均无终端执行权限。

你可以追问风险、跳过、改变方向或结束排查。新消息会先结束旧推理回合；取消 Agent 不会中断你自己正在运行的终端命令。主机/连接代次变化会使旧建议失效。

自动分析同样使用所选模型，可能产生费用；同一持续输出状态不反复触发，敏感输入保守抑制，部分脱敏输出仍能分析。运行中／交互程序的稳定可见输出可以给建议，但不表示执行结束；可信完成后可再跟进。建议只复制、不执行，三个选项不是连续执行计划。关闭共享画面后可重新打开原 PTY，新画面须重新授予观察权限。

### 观察结果不确定时

有现成 OSC 133 shell integration 时使用真实命令边界和退出码；没有可靠标记时显示不确定，避免把密码/交互输入当成命令。应用不注入辅助命令或自动安装 integration。可手动粘贴必要且已脱敏的输出继续分析。

已有 iTerm 读取当前可访问文本及后续快照，可能含部分滚屏，但不保证完整历史。“从现在开始”不发布授权前内容，只保守采集新增完整行；“当前上下文＋继续”加入当前有界快照／共享 PTY 有界缓存。暂停或结束清空证据，重新授权从新时间点开始，不补采暂停内容。结束协作不关闭 iTerm，解除已有绑定不发送命令。共享 PTY 由墨巡持有，退出墨巡会终止桥接。详见 [外置终端说明](../EXTERNAL_TERMINALS.md)。

## 文件审批

文件修改弹窗展示全部文件 Diff、完整原文/新文、理由和有效期。检查后选择批准、拒绝或要求调整。

- 修改/覆盖/删除/移动现有文件需逐项勾选。
- 审批仅对本次精确内容有效，5 分钟内一次性使用；文件变化后应重新申请。
- 需要持久备份时，在批准前从“完整文件”复制原内容到自己的备份。
- 批量遇错停止，弹窗/结果会标出已变更或可能变更的路径；据此检查实际文件，不假设自动回滚。
- 大于 64 KiB、二进制、敏感路径、symlink/hardlink 等须人工处理；新目录与其内部文件应分批申请。

文件批准不授予任何终端执行权限。

## 图片、日志与 PDF

- 支持 PNG/JPEG/WebP，文本/代码/日志/配置和文本 PDF。可拖入、粘贴，预览后移除不需要的附件。
- 自定义模型设置中，在支持视觉的模型行后添加 ` | image`，例如 `my-vision-model | image`。仅在供应商确实支持时声明。
- 文本模型会在发送图片前提示更换模型。图片会以真实图片数据块发送，并非只给模型文件名。
- 每回合最多 8 附件、总计 20 MiB、单文件 5 MiB。PDF 文本提取限 2 MiB/30 页；扫描 PDF 请转成页面图片。
- 图片限 8192px/16MP，发送时缩至最长边 2048px；过密截图建议裁切关键区域。
- 文字自动进行常见密码/Token/私钥模式脱敏。图片发送前会弹出原生隐私确认；须自行遮盖像素中的敏感内容。
- 不支持的格式明确报错。附件中的脚本或指令不会取得执行权限。

## 主题与兼容

侧栏外观入口仅有“墨巡 · 宣纸”和“墨巡 · 夜墨”；新安装默认浅色，旧四套深色主题映射至夜墨。切换无需重启、不重建终端；浅色代码／日志用暖灰背景，iTerm 继续使用自己的 Profile 配色。

品牌显示名变为墨巡，Bundle ID 仍为 `com.crescent.app`；默认数据仍在 `~/.crescent`。Chromium/本地设置继续使用原 `Crescent`（安装版）或 `crescent`（开发版）目录。历史会话、知识库、SOP 和连接不因改名删除；仅清理旧命令手册的两个 JSON 文件和废弃布局值。

旧执行模式设置不再赋予权限。历史执行记录仅供查阅。MCP 配置仍可维护和人工发现，但当前 Agent MCP 审核白名单为空，所有 Agent MCP 调用均禁用。

## 数据保留与隐私

| 数据                     | 保留方式                                                               |
| ------------------------ | ---------------------------------------------------------------------- |
| 原始人工键盘输入         | 观察器不长期保存；不确定/敏感输入不采集                                |
| 脱敏终端观察             | 每终端 20 事件，16K 字符/事件、64K 总量、30 分钟内存；换目标/关闭清理  |
| 单回合观察上下文         | 默认 32K 字符，可设置 8K–64K；包含序列化元数据预算                     |
| Guided Ops 步骤          | 内存中最近 30 条，每会话 30 分钟有效；普通聊天记录按原工作台历史保存   |
| 安全审计                 | 1000 条、24 小时内存元数据；重启清空                                   |
| 完整文件审批             | 临时 owner/run 作用域，完成/取消/过期失效；不作为普通工具参数持久化    |
| 导入/粘贴附件            | `~/.crescent/attachments`；启动及每小时清理修改时间超过 24 小时的文件  |
| 历史附件路径             | 聊天引用可能保留，但临时附件清理后需重新添加；请自行保管重要原文件     |
| 用户原始文件             | 选择或拖入已有路径不意味着应用会删除源文件；只有审批中的精确变更可修改 |
| 既有会话/知识库/SOP/设置 | 沿用原存储和用户删除/导出流程，不因品牌升级整体清理                    |

发送后，必要上下文由你选择的模型供应商处理；其保留策略由供应商决定。自动脱敏不能识别全部业务机密，发送前请只保留本次排查所需内容。

当前本地 Mac Intel（x64）包关闭签名/公证，仅供开发验收。应用名为“墨巡”，安装包前缀为 `moxun`。正式分发还需单独完成签名、公证与 Intel 真机人工验收。
