# 墨巡水墨山河主题规范

## 主题名称

- 浅色：水墨山河 · 宣纸（moxun-ink-wash-light）
- 深色：水墨山河 · 夜墨（moxun-ink-wash-dark）

这是一套中性黑白灰主题，与最终定稿的“水墨群山 + 蜿蜒河流”品牌图标保持一致。它不是旧的蓝黑科技主题换色，也不是传统古风主题。

## 视觉原则

1. 宣纸白、墨黑、岩石灰、淡墨灰构成主色阶。
2. 以留白、细分隔线和清楚的面板层级建立秩序。
3. 主要内容区域不铺设纹理，不使用霓虹渐变。
4. 水墨山水只作为品牌展示，不作为工作内容的底纹。
5. 终端、代码、日志、Diff、表格保持纯色背景和高可读性。
6. 颜色、边框、阴影、圆角必须来自统一 Token。

## 两种变体

### 宣纸（Light）

- 主背景：#F7F7F3
- 卡片：#FCFCF9
- 主文字：#171918
- 次级文字：#626964
- 边框：#DADDD6
- 终端：#171A18，文字 #E3E7DF

整体应明亮、克制，不要纯白刺眼，也不要把整个工作区做成灰色块。

### 夜墨（Dark）

- 主背景：#111312
- 面板：#191D1A / #202421
- 主文字：#F1F2ED
- 次级文字：#C0C4BD
- 边框：#363C37
- 终端：#090B0A，文字 #D9DED6

深色变体应保持黑白灰层次，不增加蓝紫、青绿霓虹强调色。

## 组件规范

- 顶部栏：清晰的品牌区和工具区，弱化装饰。
- 侧栏：与主工作区拉开一个明度层级，当前选中态清楚。
- 卡片：细边框、轻阴影或无阴影，避免厚重玻璃拟态。
- 输入区：与消息列表分层明确，支持多模态附件预览。
- 命令建议卡：突出命令、目标主机、风险和预期结果；只提供复制、追问，不提供执行入口。
- 文件审批 Diff：保留新增/删除/修改的语义色，但以中性色为底。
- 终端：纯色背景、等宽字体、可选中和复制，不叠加水墨纹理。
- 表格和日志：不使用水印，保证对齐和可读性。

## 山水图像使用边界

- 欢迎页、空状态、关于页可以展示完整山水主图。
- 工作区留白区域如需水印，透明度控制在 3%–6%。
- 不得将山水图铺在终端、日志、代码、Diff、表格或输入文字后面。
- 水印延迟加载；在高密度工作区不加载。
- 必须有纯色回退。
- 不要额外加入月亮、月牙、墨滴、圆环、轨道、定位点等旧方向元素。

## 动效与可访问性

- 仅使用轻微淡入、hover 和状态过渡。
- 遵循 prefers-reduced-motion。
- 普通文字对比度至少 4.5:1，大文本至少 3:1。
- 焦点、禁用、选中、错误状态不能只靠颜色表达。
- 主题切换不重载应用，设置应持久化。

## 接入要求

Codex 必须先检查项目现有主题注册、CSS Variables、持久化和组件样式，再把本规范映射到现有主题系统。不要另建并行主题系统，不要在组件中散落硬编码色值。
