# 墨巡可靠终端 · 阶段三实施记录

2026-11-07。按最新指示开始阶段三和四，阶段二已知性能和会话迁移问题继续记录。本阶段交付首批本机受控执行。

## 使用和范围

在当前对话中从侧栏选「打开本地协作终端」。状态出现「本地协作 · 逐条审批」后，可在聊天中要求 Agent 执行 `pwd`。每次请求均通过绑定聊天窗口的原生审批，默认焦点为拒绝。审批展示完整命令、本机、目录、会话、风险、期限与输出披露范围。批准的命令在同一个可见 Bash PTY 执行。

当前支持 `pwd`、`true`、`false`、`uname` 和单个 `-s`、`-r`、`-m` 参数，以及受限字面量的 `echo`。旧 iTerm、保存连接、SSH、交互命令、管道、多行脚本和带副作用的命令仍走人工操作。人工键入、粘贴或中断前，Main 会撤销该 PTY 的协作权限。要重新启用，先明确结束会话，再打开新的协作终端。当前只保留一个墨巡 PTY。普通窗口关闭后可重开，同一对话保持原 PTY。

## 实现

- `src/main/terminal/managed/command-executor.ts` 生成独立的审批 ID、命令 ID、命令哈希和随机 nonce。受控本地 Bash 禁用个人启动配置和历史，Main 根据绑定的 OSC 133 提示符及固定 Envelope 判断状态。匹配结束帧、有效退出码和返回可信提示符后才报告完成。
- `session-manager.ts`、`window.ts` 和 `src/shared/managed-terminal.ts` 保持 Main 权威。写入前重验会话、generation、attachment、窗口可见性、当前聊天和运行。隐藏窗口无法启动新命令，用户输入先于 Agent 权限撤销。普通 Agent-origin 原始写入仍被拒绝。
- `src/main/agent/pi-managed-terminal-tool.ts`、`pi-host.ts`、能力表和提示词仅为符合条件的对话提供 `request_terminal_command`。旧 Bash 入口、子 Agent、SSH 和观察触发的主动分析保持人工执行路径。退出应用先停止新的 Agent 调度并取消现有运行，再回收 PTY。
- 审批和结果审计保留有界内存元数据。Agent 收到状态、时间、目标、退出码及有界脱敏输出。Shell 结果和业务验证单独表达。软超时保留正在运行状态及会话锁，缺失证据时进入未知，执行器没有重发路径。

## 验证

| 场景 | 结果 |
| --- | --- |
| CI 协议测试 | 4 项通过。覆盖分块、错误身份与 nonce、先结束后开始、退出码、过期、隐藏、拒绝、软超时及接管 |
| 真实 Electron 与 Bash/PTY | 通过。Agent 来源的原始写入被拒绝，批准后的命令与人工输入共享原 PTY。验证退出码 0 和 1 |
| 真实 Electron、Pi 与回环模型 | 通过。12 次模型流请求中产生 4 次审批。两个获批命令分别返回退出码 0 和 1。拒绝、隐藏、跨对话和人工接管均未写入候选命令 |
| 轻量命令 Envelope 时间 | 同一夹具的两个获批命令从收到开始到完成确认分别为 1 ms 和 0 ms，记录粒度为 1 ms。整个夹具约 6 秒，包括启动和回环模型。原生人工审批耗时与真实供应商响应未测 |

第一次回环模型夹具尝试保存测试凭据时触发 macOS 凭据存储提示。只读核对确认 `login.keychain-db` 文件仍在，仍是默认用户钥匙串。后续夹具使用现有进程内运行时入口，临时值仅用于回环模型，应用的凭据存储实现没有改动。

## 未解决事项与回滚

当前生产权限仅覆盖受控本机 Bash。远端 Bash/Zsh、可验证的 SSH 主机及目录变化、交互式命令的等待状态、人工接管后安全重建权限、只读自动模式和持久化审计尚待实现或验收。阶段一的回环 SSH 探针属于隔离协议证据。相同 PTY 流内的 nonce 提供关联能力，已知 nonce 的生产者仍能伪造同格式控制帧，因此任意 Shell 代码继续使用人工路径。

如需回滚，先移除 `request_terminal_command` 的注册及能力表条目，再撤回协作入口和 Executor 接线。普通人工终端的窗口、PTY 和缓存可保留。工作树存在前序未提交改动，回滚应针对本阶段增量。
