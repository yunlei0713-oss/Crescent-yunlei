## 响应时间实测

Intel macOS 开发机，Node/Vitest 独立进程。每项执行 7 次，使用同一合成 UTF-8 日志生成方式，唯一命中项在文件尾部。P95 为该 7 次样本的最近秩分位值。

| 合成日志大小 | 字面搜索 P50，改前 → 改后 | 字面搜索 P95，改前 → 改后 |
| ------------ | ------------------------: | ------------------------: |
| 26.0 MiB     |        430.71 → 112.23 ms |        590.16 → 152.61 ms |
| 101.0 MiB    |       2299.43 → 430.15 ms |       2581.70 → 439.84 ms |

改后两组局部读取均保持约 15 KB 的结果。另用 30 个标签页、25 次热写入对照测试，保持同一套 SQL 和预编译语句，仅切换外层事务。SQLite 保存 P50 为 94.72 → 3.65 ms，P95 为 154.58 → 5.18 ms。两组测试均为本地耗时，模型供应商首字耗时需另做采样。
