## 1. 交付行为

- 左下角独立应用底栏提供桌宠、主题、Crescent GitHub 三个入口；桌宠和主题已从右上角移除。底栏占用正常布局高度，不覆盖终端、子终端或聊天输入。
- 桌宠通过独立偏好 `crescent.petVisible` 持久化，默认隐藏。按钮只改变显示偏好，不调用 `whale-monitor:save-settings`，不改变额度监控 `enabled`。
- 空端点、没有密钥或暂停监控时，基础宠物和设置仍可使用。用量状态明确显示未配置；用户主动查询时才提示所需端点和 API Key。
- 设置允许保存空端点和普通参数；非空端点继续验证协议、内嵌凭据和长度，预算与刷新间隔继续验证。API Key 的既有主进程加密和快照脱敏路径保留。
- 额度轮询按用量、模型端点分别判断条件。配置变更取消旧请求、撤销旧结果的写入资格，避免旧密钥或旧服务响应污染新配置。
- 快照失败保留宠物、显示重试入口；设置失败保留输入并在设置视图显示错误。后台快照不会覆盖正在编辑的草稿。
- 点击状态文字直接打开额度面板；宠物保留单击互动、双击详情和拖拽。Escape 关闭详情，视频失败回退静态图。关闭后释放订阅、视频、动画帧和定时器。
- 主题菜单从底栏向上、向右展开，保留方向键、Escape、外部点击关闭及焦点返回。GitHub 固定链接经过现有 `app:open-external` 安全路径；失败显示简短提示。

## 4. 上游与相似项目的取舍

实时核对 [yanzwzz 的 v0.3.10 Release](https://github.com/yanzwzz/dsh-whale-girl-pet/releases/tag/v0.3.10)和[官方更新记录](https://github.com/yanzwzz/dsh-whale-girl-pet#readme)：最新 Release 仍为 2026-10-14 的 v0.3.10。其主要修复是完成气泡缩短为类型/耗时、区分非零退出，并处理中文括号字形。相较前几版，位置编辑、贴边隐藏、聚合任务状态、触屏拖拽和工作动画恢复也是值得比较的方向。

| 分类                 | Crescent 的选择                                                                                                                                                                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 可直接借鉴的逻辑     | 可选监控不能阻断宠物；工作动画结束仍按当前 busy 事实选择动作；pointercancel 清理拖拽；故障降级和必要信息提示。本轮保留/验证这些行为，不复制上游命令气泡。                                                                                                    |
| 需要 Crescent 适配   | 位置/尺寸编辑、贴边偷看、睡眠、等待审批/失败动作、完成气泡等需映射主进程权威 Agent 状态，尤其不能将子任务结束当成主任务完成；本轮不新增这些体验。                                                                                                            |
| 依赖 DSH，不直接移植 | DSH profile、jobs、usage ledger、插件路由和 settings API。Crescent 继续使用自己的 Electron/React、preload IPC 和监控存储。                                                                                                                                   |
| 素材授权             | 保留 `src/renderer/src/assets/licenses/dsh-pet-animation-assets.txt`，其记录素材来源和非商业限制；不将素材视为 MIT，不新增第三方动画。GitHub 图标用已安装 Lucide factory 构造历史 Lucide 图形，并附 ISC 声明。正式分发仍需核对包中附带的素材声明及使用场景。 |

- [vlln/whale-girl](https://github.com/vlln/whale-girl)：状态/互动及 Tauri 桌面伴侣可作后续参考；其 DSH API 与独立壳不进入本次产品。

- [lyl1352/whale-girl-desktop-pet](https://github.com/lyl1352/whale-girl-desktop-pet)：面向 Windows/PowerShell 的桌面集成，不搬入当前 Mac 实现。
- [Aibie07/whale-girl-desktop-pet](https://github.com/Aibie07/whale-girl-desktop-pet)：README 说明素材另从 Release 下载，且其他用途需自行取得素材作者授权；修正原计划“素材自包含”的概括，本轮不下载或复用。

以上适配建议是结合 Crescent 架构的判断，不代表这些第三方实现已在 Crescent 中运行验收。
